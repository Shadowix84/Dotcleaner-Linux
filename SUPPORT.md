# Getting help

1. **Read the [FAQ](README.md#faq)** — it covers the most common questions (first launch, `._` files
   coming back, the drive's Trash, Intel Macs and Linux).
2. **Something went wrong?** Open a [bug report](https://github.com/Shadowix84/Dotcleaner-Multi-Software/issues/new?template=bug_report.yml).
3. **An idea, or a junk file Dotcleaner should clean?** Open a [feature request](https://github.com/Shadowix84/Dotcleaner-Multi-Software/issues/new?template=feature_request.yml).
4. **A translation to fix or a new language?** Open a [translation request](https://github.com/Shadowix84/Dotcleaner-Multi-Software/issues/new?template=translation.yml).
5. **Just want to chat?** Join the [Discord](https://discord.gg/4FbhkuhRMm).

Security issues: see [SECURITY.md](SECURITY.md).
